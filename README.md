# 📝 TP2 – Gestion d’une application de suivi de séries et films

## Lancement de l'application 

### Cloner le projet 
```
git clone -b TP2 https://github.com/MaindyG/CID_TP1.git
```

### Ouvrir le dossier TP1
```
cd tp1
```

### [AU BESOIN] Installer les dependances
```
npm install
```

### Initialiser la BD avec des données 
```
npm run seed
```


### Lancer le serveur en mode dev [BD: mongodb://localhost:27017/cid_tp2_dev ] 
```
npm run dev
```

### Lancer le serveur en mode prod [BD: MongoDB Atlas Cloud  ] 
```
npm run start
```

### Tester les routes POSTMAN
```
npm test
```
